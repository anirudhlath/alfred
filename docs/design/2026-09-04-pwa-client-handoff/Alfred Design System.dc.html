Alfred · design system · Study

A warm room with one instrument in it.

Everything below is what the prototype uses. Two type families, one accent, a fixed set of status words, and a motion spec for the only interaction that has to feel heavy. Phone · Desktop · Architecture

Colour

Warm neutrals because the thing lives in a home and speaks; cool greys read as a server room. Both themes are near-monochrome so that the single accent, amber, always means the same two things: Alfred's presence, and a decision waiting on you. Amber is never decorative and never used for success or for data. Eight stream hues share one lightness and chroma so no source shouts.

Errors have no red: they are amber (it needs you) or muted (it stopped). Red is reserved for nothing, so that if it ever appears the user knows it is not from Alfred.

Type

DM Sans for everything a person says or reads; Geist Mono for everything the machine says about itself (times, ids, tool names, status). The rule is the meaning: if the string came from the system and is meant to be exact, it is mono. Alfred's voice is one size larger than yours, always.

Spacing & shape

A 4pt grid with a short ladder: 4 · 8 · 12 · 16 · 24 · 40. Page gutter 24 (Room) and 16 (Workshop, where density matters). Every tappable thing is at least 44pt tall; if it is visually smaller, the hit area still is not.

Elevation

No drop shadows anywhere inside the app. Depth is one step of surface tone and a 1px line; layers are told apart by motion and by inverting ink and paper.

0 · bg — the Room, benches
1 · surface — banners, payloads, cards (+1 tone)
2 · sheet — rises from bottom, 28 radius, scrim 45%
3 · workshop — full layer, same bg as Room, rises
4 · door — full layer, ink and paper swapped
5 · gate — identity, full layer, presence field shown

Motion

Two curves only. rise = cubic-bezier(.2,.8,.2,1), 380–420 ms, for anything entering from the bottom. settle = cubic-bezier(.2,1.4,.3,1), 600 ms, a slow overshoot used once: when the Door's handle lands. Nothing fades in; things arrive or they were already there. Reduce-motion turns the presence field static and makes rise a 200 ms opacity step.

THE DOOR · APPROVAL, NO HAPTICS
complete: slow start → travel → 85% → snap on, overshoot 4pt, settle 600 ms
released early: snaps home in 260 ms, no state change, hint text returns
arrival
Sheet rises over whatever is showing, 420 ms rise. Ink and paper invert so the layer is unmistakably different. The fuse ring is already drawn from the real TTL; no count-in animation.
weight
Handle travel is track width − 64 (≈ 289pt at 393). The first 25% of finger travel moves the handle at 0.6×, the rest at 1.13×: it feels like it has to be pushed loose. Hint text fades over the first half.
commit
≥ 85% on release commits. Handle snaps to the end with settle (600 ms, overshoot ~4pt). Title reads "Confirmed · queued"; foot names the request id it now waits on.
applied
Only when home_action_results carries the same request_id. Dot turns the one green; word becomes "Applied" with the reported time. No animation, just the word changing; the weight was spent on the slide.
fuse
Ring is a conic arc over 300 s, stepped once per second (linear 900 ms between steps). Under 30 s the arc changes from accent to paper; nothing turns red, nothing pulses. The number is mono 40pt so the last digits are legible from arm's length.
expiry
Ring empties, track is replaced by the word "Expired" with a hollow dot, and a struck-through tombstone is appended to the Room: "Unlock the front door · expired 07:46 · not done". Consumed-elsewhere (404 on confirm) uses the same tombstone with "already answered".
offline
Track is disabled and greyed; foot reads "Cannot confirm while offline; the fuse is still running on the server." The ring keeps ticking from the last-known TTL, labelled as such.
HOLD TO TALK
Button scales 1.12 on press, fills amber, shows a 4-bar level meter; a mono counter above reads "recording 0:04 · release to send". On release: dashed bubble "Transcribing…" until the server's text replaces it in place.
WORKSHOP
Rises 400 ms over the Room, same bg. Sheets (why, held back) rise 380 ms with a 45% scrim. Pause: new events are counted on the button, not inserted; Resume inserts them at the top in one step, no per-row animation.
